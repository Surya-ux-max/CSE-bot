# CSE-Bot Client Documentation

Welcome to the comprehensive technical documentation for the **CSE-Bot Client Application**. CSE-Bot is an AI-powered academic assistant for the Computer Science & Engineering department at Sri Eshwar College of Engineering, powered by React 19, Vite, Tailwind CSS v4, and a multi-agent backend architecture.

## 🚀 Key Client Highlights

- **React 19 & Vite 8 Core**: Fast build pipeline and seamless state management.
- **Tailwind CSS v4 & Glassmorphism**: Custom CSS variables, dark/light theme switching, and responsive design system.
- **Mobile First & Portable**: Touch-optimized interface, dynamic mobile viewport height (`h-dvh`), mobile Virtual Robot drawer modal, and automatic local LAN host resolution for testing on mobile devices over Wi-Fi.
- **OOP Architecture**: Object-Oriented service layers (`ApiClient`, `SessionManager`) and domain models (`ChatMessage`).
